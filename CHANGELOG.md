# Changelog

All notable user-facing changes will be recorded in this file.

## v1.0.0 - 2026-05-24

First public release.

- Added a portable Windows desktop app for merging PDF files locally.
- Added file picker and drag-and-drop PDF selection.
- Added selected-file display, duplicate skipping, removal, select all, and file reordering.
- Added PDF merge output selection, overwrite confirmation, temporary-output safety, and friendly failure messages.
- Added English and Hebrew localization with right-to-left layout for Hebrew.
- Added persisted language, theme, and window placement settings.
- Added light, dark, and system theme selection.
- Added local file logging under the portable `data\logs` folder.
- Added self-contained `win-x64` portable packaging.
